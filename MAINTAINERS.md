# Maintainers

Maintainers review contributions, make compatibility decisions, manage security
reports, and publish releases.

## Current maintainers

- [Emergent Interactive](https://github.com/emergentinteractive) (`@emergentinteractive`)

## Decision making

Changes are discussed in issues and pull requests, with preference for consensus and a
stable public API. The maintainers make the final decision when consensus cannot be
reached. A maintainer with a personal conflict should step away from that decision.

New maintainers may be invited after sustained, constructive participation. Existing
maintainers approve additions and removals and update this file and CODEOWNERS together.
